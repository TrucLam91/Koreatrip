# 🇰🇷 Korea Trip Guide — June 2026

A complete travel guide for couple travel in South Korea: hotels, hanoks, attractions, food & nightlife.

## 🚀 Deploy to GitHub Pages (3 steps)

1. **Create a new GitHub repository** → name it `korea-trip-2026` (or anything you want)

2. **Upload `index.html`** to the repository root:
   - Go to your repo → click **"Add file"** → **"Upload files"** → drag `index.html`
   - Commit the file

3. **Enable GitHub Pages**:
   - Go to repo **Settings** → scroll to **"Pages"** section
   - Under "Source" → select **"Deploy from a branch"**
   - Branch: **main** / Folder: **/ (root)** → click **Save**
   - Your site will be live at: `https://YOUR-USERNAME.github.io/korea-trip-2026/`
